🕹 Sobre o Projeto

Este projeto é uma aplicação de Lista de Compras desenvolvida utilizando Flask e SQLite.

O sistema permite cadastrar, visualizar, editar e excluir produtos de uma lista de compras.

🎒 Informações dos produtos
  • Nome
  • Descrição
  • Categoria
  • Foto
  • Status

Os produtos podem ser organizados em categorias como Alimentos, Limpeza, Higiene, Bebidas e Outros.

🏆 Projeto desenvolvido para prática dos conteúdos estudados nas aulas de Flask.
